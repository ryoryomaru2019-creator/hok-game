💡 称号スコア判定の仕組み ＆ 設計のヒント

SYSTEM GUIDE

📊 スコア判定の優先順位

ゲーム終了時、獲得したスコアと各階級の「必要スコア」が比較され、条件を満たした中で最も高い階級の称号がプレイヤーに付与されます。

  • 必要スコアは自動的に降順（大きい順）でソートされて判定されます。
  • 最下位の称号は「0点」に設定しておくことで、どんなスコアでも必ず何かの称号が付与されます。
  • 上位の称号にはプレミア感のある絵文字（👑, 🐉, 🌊など）を付けるとプレイヤーの挑戦意欲が高まります。

SECURITY & MODERATION

🛡️ ユーザーブロック（非表示化）の仕組み

不適切なプレイヤー名や不正スコアが疑われるエントリーは、「ブロック」ボタンまたは一括操作でランキングから除外できます。

  • サイレント除外: ブロックされたユーザーID（内部タグ）はローカルストレージ（hirame_blocked_users）に安全に記録され、ランキング集計・表示から完全に除外されます。
  • プレイ継続性: ユーザー自身のブラウザ上でのゲームプレイやX（旧Twitter）への結果シェアはブロックによって阻害されず、コミュニティの摩擦を最小限に抑えます。
  • ブロック解除: テーブル内の「解除」ボタン、または一括操作ボタンからいつでも即座にブロックを解除してランキングに復帰させることができます。

📖 最短3ステップ！Googleスプレッドシート＆GASの設置手順

  1. Google スプレッドシート を新規作成し、タイトルを「HoK！世界ランキングデータベース」などにします（シート名は空のままでOK、自動作成されます）。
  2. 上部メニューの「拡張機能」→「Apps Script」を開き、エディタ内の既存コードをすべて消して、右上の「📋 GASスクリプトコードをコピー」ボタンでコピーしたコードをそのまま貼り付けます。
  3. 右上の「デプロイ」ボタン →「新しいデプロイ」を選択：
    ・種類の選択（歯車アイコン）: 「ウェブアプリ」を選択
    ・次のユーザーとして実行: 「自分（your-email@...）」
    ・アクセスできるユーザー: 「全員 (Anyone)」 ※必須（ゲームプレイヤーが匿名でスコア送信できるようにするため）
  4. 「デプロイ」を押し、表示された「ウェブアプリのURL」をコピーして、上記の「Google Apps Script ウェブアプリURL」欄に貼り付けて「URL保存」を押せば完了です！

Step 1: 何を仕分けさせますか？

１，「何を仕わけさせますか？」(A／B／両方を仕分け)

ゲームのタイトルと、仕分け対象となる2大陣営「A」と「B」の名前を入力してください。

ゲーム中の「A派モード」および「バケツA」の名称になります。
ゲーム中の「B派モード」および「バケツB」の名称になります。
