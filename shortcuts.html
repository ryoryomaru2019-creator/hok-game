⌨️ キャラクタースタジオ 操作＆ショートカットキー一覧 Photoshop準拠

ベジェ曲線パス操作・キャンバス操作・全ツールのショートカット一覧です。

✒️ A. パス・ベジェ曲線ツールの操作

キー / マウス操作 機能名 詳細な動作
Alt + ハンドルドラッグ ハンドルの折り曲げ (分割) スムーズポイントの片側ハンドルだけを独立して折り曲げ、コーナー化します。※もう一度 Alt を押してドラッグすると反対側ハンドルと一直線に再連動します。
Alt + アンカークリック コーナー / スムーズ切り替え アンカーポイントの直線（角）と曲線（スムーズ）をトグル切り替えします。ダブルクリックでも同様に切り替え可能です。
Alt + ドラッグ (アンカーから) ハンドルの引き出し コーナーポイント（直線）から両側に新しいベジェハンドルを引き出して曲線化します。
パス線上をクリック アンカーポイントの追加 ペンツール選択時、既存パスの線分上をクリックするとその位置に新しいアンカーポイントを挿入します。
アンカーポイントをクリック アンカーポイントの削除 ペンツール選択時、既存アンカーポイントをクリックすると削除（マイナス化）されます。
パス線を直接ドラッグ セグメントの直接変形 ダイレクト選択ツールまたは選択ツール時、パスの曲線を直接マウスでドラッグして直感的にふくらみを調整できます。
Shift + ドラッグ 45° 角度スナップ ハンドル操作やアンカー移動時に、水平・垂直・45度単位に角度をきれいに固定します。
Delete / Backspace 選択アンカーの削除 現在選択されているアンカーポイントをパスから削除します。
Ctrl + クリック / 背景クリック 選択解除 アンカーポイントの選択を解除します。

🖼️ B. キャンバス・画面表示の操作

キー / マウス操作 機能名 詳細な動作
Space + ドラッグ 一時的な手のひらツール どのツールを選択中でも、Spaceキーを押している間は手のひらツール（Pan）になり、画面を自在にスクロール移動できます。Spaceを離すと元のツールに戻ります。
マウスホイール回転 カーソル中心ズーム マウスカーソルの位置を中心として、滑らかにズームイン・ズームアウトします。
ズームツールでクリック ズームイン (拡大) クリックした位置を中心に 1.25 倍ズームインします。
Alt + ズームツールクリック ズームアウト (縮小) クリックした位置を中心に 0.8 倍ズームアウトします。
Ctrl + 0 全体表示 (画面にフィット) キャラクター全体が現在のキャンバス画面の中央に収まるよう自動スケーリングします。
Ctrl + 1 100% 等倍表示 ズーム倍率を正確に 100%（等倍）にリセットします。
Ctrl + + / - 段階ズーム 段階的に画面を拡大・縮小します。

⚙️ C. ツール切り替え ＆ 全体編集ショートカット

ショートカットキー 機能名 詳細な動作
Ctrl + T または ツール ⤢ スケール・回転 スケール・回転 (バウンディングボックス) オブジェクトや選択パス（複数）の周辺にPhotoshop風バウンディングボックスを表示して拡縮・回転します。
・拡大縮小 (スケール): 周辺8箇所の四角ハンドルをドラッグ
・回転: バウンディングボックスの四隅のやや外側にカーソルを合わせてドラッグ
・Shift + ドラッグ: 縦横比を固定して拡縮 / 回転時は15°刻みスナップ
・Alt (Mac: Option) + ドラッグ: オブジェクトの中心から操作
・Shift + Alt + ドラッグ: 中心基準かつ縦横比固定で拡縮
・確定: Enter キー
・キャンセル: Esc キー (またはキャンバスの何もないところをクリック)
Ctrl + E 複数レイヤーの結合 / 下のレイヤーと結合 複数選択されたレイヤーを1つに統合します。単一選択時はPhotoshop同様に「下のレイヤーと結合」します。
Ctrl + A すべて選択 (Select All) キャラクター内のすべてのパーツ・レイヤーを一括選択します。
Ctrl + D 選択を解除 (Deselect) すべてのパーツ・アンカーポイントの選択状態を解除します。
Ctrl + J レイヤーの複製 (Duplicate) 選択中のパーツ・レイヤーを複製して配置します。
Ctrl + G / Ctrl+Shift+G レイヤーのグループ化 / 解除 選択中のパーツをグループ化してまとめます。Shift併用でグループ解除します。
M 矩形選択ツール (Marquee) ドラッグした四角形エリア内の複数のオブジェクトやパスを一括選択します。※選択ツール(V)で背景をドラッグしても矩形選択可能です。
Shift + クリック 複数パーツの追加選択 キャンバス上の複数パーツを1つずつ追加・除外して複数選択します。
レイヤーをドラッグ＆ドロップ レイヤーの並び替え ＆ 親子付け レイヤーリストで上下にドロップして前後順序を変更、中央にドロップして子レイヤー化。⏏️ボタンで親から解除可能。
V 選択ツール オブジェクト全体のみの選択・移動ツールです。パスやベジェハンドルには触れません。Ctrl+Tで拡大縮小・回転が可能です。
A ダイレクト選択ツール アンカーポイントやベジェハンドル、セグメントの個別編集ツールに切り替えます。
P ペンツール ベジェ曲線のアンカー追加・編集ペンツールに切り替えます。
C / Shift + P 曲率ペン (アンカーツール) アンカーポイントツールとして、パス上のポイントやコントロールハンドルに触れて曲率を直感調整します（意図しないポイント挿入は行いません）。
R / E / T / U シェイプツール R: 長方形、E: 楕円、T: 三角形、U: シェイプツールを起動します。
H 手のひらツール 画面パンスクロールツールに切り替えます。
Z ズームツール 画面ズームツールに切り替えます。
Ctrl + Z 元に戻す (Undo) 直前の操作を1つ取り消します。
Ctrl + Y / Ctrl+Shift+Z やり直し (Redo) 取り消した操作をやり直します。
↑ ↓ ← → (矢印キー) 微小移動 (ナッジ) 選択中のアンカーポイントまたはパーツを 1px 単位で移動します。Shift 併用で 10px 移動になります。
Shift + クリック / Ctrl + クリック レイヤーの複数選択 レイヤーパネルで複数の部位レイヤーをまとめて選択します。キャンバス上の矩形選択（ラバーバンド）とも連動します。
Ctrl + C / Ctrl + V レイヤーの一括コピー＆貼り付け 選択した全レイヤーをクリップボードにコピーし、位置を +15px ずらして複製追加します（親子関係を自動維持）。
Delete / Backspace 選択レイヤーの削除 選択中の全レイヤーを一度に削除します。
[ / ] 線幅の変更 選択中のパーツの線幅を 0.5px 刻みで細く / 太くします。
Ctrl + S ゲームに適用 現在のキャラクター編集データをゲーム本編に即時反映します。
🪄 AIキャラ生成 Gemini AI キャラ自動生成 参考画像やプロンプトから、ゲーム専用のベクターパーツ構造を持った新キャラクターを完全自動生成します。
F1 または ? ショートカット一覧 この操作・ショートカットキー一覧ウィンドウを開きます。
